# Feature map

Read the feature needed for the change. Run every row for a maintenance pass, serially on one
owned Worker using the parent skill's launch and cleanup. Source bindings and selected browser
files live in `scripts/algebra-features.mjs`. Use these exact six group IDs with `--feature`.
A group pass proves only its executed journeys. Shared journeys can belong to several groups;
do not add their case counts as unique coverage. Reconcile the generated map after source
integration, then use the parent skill's full release pass for current execution evidence.

| Feature                                       | User-facing scope                                                                            |
| --------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [Beginner language](beginner-language.md)     | One editable map, symbol meanings, quantifiers, exact witnesses and codomain changes         |
| [Discovery](discovery.md)                     | Home, units, laboratories, reference, sources, lessons and concept navigation                |
| [Guided learning](guided-learning.md)         | Typeset teaching, checkpoint feedback, proof recall, retained editions, writing and transfer |
| [Laboratories](laboratories.md)               | Catalogue entry, diagrams, square actions, representation journeys and recovery              |
| [Accounts and progress](accounts-progress.md) | Owned progress and arguments, explicit import/export, conflicts and recovery                 |
| [Agent access](agent-access.md)               | CLI discovery, declared interactions, browser tools and build provenance                     |

Group IDs are `beginner-language`, `discovery`, `guided-learning`, `laboratories`,
`accounts-progress` and `agent-access`. Discovery owns search-preview layout. Guided learning
owns reader and citation mathematics. Laboratories owns mathematical choices, diagrams, tables,
numerical boundaries and feedback. Shared controls require the affected groups as well as
the full release pass. Native provider sign-in needs separate evidence.
