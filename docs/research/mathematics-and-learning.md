# Mathematics and learning decisions

Issue: #75. Baseline: `acb8486`. Scope: the existing 150 concepts only.

## What was actually inspected

The lesson definition/theorem/proof corpus, guided assessments, learning metadata, unit definitions, historical September audit and proof-dependency records were read. Targeted model inspection covered group actions, semidirect products, induction, characters, tensor balancing, quotient ideals, localization, orthogonal geometry and Wedderburn layers. This report does **not** certify every implementation branch or browser behavior. Browser evidence belongs in the feature map and release report.

Baseline counts were 150 lessons, 79 guided lessons, 40 worked illustrations, 23 reference-only entries and eight proof roadmaps. Twenty-four lessons had no worked-example field; 34 lacked practice; 17 lesson prerequisite arrays differed from learning metadata. These are verified data facts, not claims about student outcomes.

The previous overhaul had already repaired action conventions, scalar-versus-ordinary kernels, tensor module sides, and the Artinian/Nakayama circular-proof hazard. Those repairs remain. Existing official-course, textbook and reconstructed URECA citations were retained. Access-controlled source files were not reopened, copied or claimed independently verified. The URECA provenance remains an agent reconstruction, as documented in `docs/audit-2026-09-22/URECA_PROVENANCE.md`.

## Verified gaps and changes

1. Seventy-one concepts lacked the full guided contract. Each now has two authored worked examples, a concrete misconception/nonexample, justified proof steps or an explicitly imported proof roadmap, prerequisite/application/boundary/transfer questions and explanatory feedback. Original 79 assessment definitions remain byte-equivalent under canonical JSON serialization; original reviewed worked/practice examples remain.
2. Standalone formula cards omitted premises present in surrounding prose. Examples: finite **abelian** classification, proper finite-index coset divisibility, irreducible-map Schur hypotheses, finite-dimensional tensor/Hom identification, Artinian commutative hypotheses, nonzero/nonunit factorization definitions, and DVR's zero convention. The cards now state those premises themselves. This is a presentation correctness defect; it was not evidence that the full contextual lessons asserted false theorems.
3. Hilbert's previous highlighted theorem was a zero-set identity while its proof addressed Noetherian polynomial rings. The highlighted statement now matches its proof; the zero-set consequence remains in the explanation.
4. Metadata prerequisites and lesson prerequisites now agree. Added dependencies distinguish basic groups, ring arithmetic, field extensions, modules, representation theory and structural results. The Hall containment quantifier now says every eligible subgroup lies in **some** Hall subgroup, avoiding the false reading that every Hall subgroup contains them all. The graph is acyclic; it does not use Artinian⇒Noetherian to establish the radical-nilpotence premise.
5. New answer positions are distributed deterministically. Existing assessment identifiers and answers remain unchanged to preserve progress semantics. Imported results remain labelled imported; adding a practice activity does not transform a roadmap into a complete proof.

The final prerequisite pass reviewed all 150 concept entries and added 81 direct edges across 60 changed entries, including generator/subgroup, cyclic/generator, isomorphism/homomorphism, Lagrange/coset, the three later group isomorphism theorems/first isomorphism, Burnside/orbit–stabilizer, orthogonality/linear algebra and character bounds/characters. Only the entry introducing maps and fibers has no earlier lesson. The quadratic-integer lesson was removed as a required predecessor of prime/irreducible: that counterexample defines its ring locally, and the earlier edge would make the UFD→irreducibility→algebraic-number route circular. Its mathematical connection remains. The audited graph passes cycle checks.

Independent review subsequently repaired proof scope or definitions in eight inherited guides (stabilizer/core, cycle index, Sylow counts, quotient rings, modules, character table, Wedderburn and radical layers). Historical whole-guide digests remain in the audit; separate baseline digests verify all four assessment fields in each of the 79 inherited guides. Those 316 assessment contracts are unchanged. Computational checks now include equivariant stabilizer-coset identification, symmetric-group coloring inventories for small degrees, integer monic reduction into Gaussian integers, the order-30 Sylow counting obstruction and exact triangular-module layers over F₂. Existing character and Wedderburn model checks independently validate the reviewed examples; none proves the imported general structure theorems.

`teaching-audit.json` records each concept's original provenance, prior status, new scaffolding, dependencies, proof boundary and evidence state. A false browser-inspected flag means no inspection evidence has yet been attached; it must not be interpreted as a pass.

## Public mathematical cross-checks

- [Keith Conrad, Group Actions](https://kconrad.math.uconn.edu/blurbs/grouptheory/gpaction.pdf): definition, actions/homomorphisms, orbit–stabilizer and the coordinate-direction warning. In a left permutation module, the output coordinate uses the inverse label permutation. We retain column-image conventions and test noncommuting swaps rather than only self-inverse examples.
- [Conrad, Transitive Group Actions](https://kconrad.math.uconn.edu/blurbs/grouptheory/transitive.pdf): coset actions and stabilizers. The primitive-action lesson explicitly requires a transitive action of degree at least two, and distinguishes the coset set from a quotient group.
- [Conrad, Semidirect Products](https://kconrad.math.uconn.edu/blurbs/grouptheory/semidirect-product.pdf): external group law and the homomorphism-to-automorphisms condition. The C₄ order-two subgroup supplies a nonsplitting counterexample, while S₃ shows that a complement need not be normal.
- [Conrad, Maschke's Theorem over General Fields](https://kconrad.math.uconn.edu/blurbs/grouptheory/maschke.pdf), pp. 1–3: averaging requires invertible group order and a conjugated projection. The modular unipotent counterexample explains why merely copying real orthogonal-complement intuition is unsafe.
- [Conrad, Tensor Products I](https://kconrad.math.uconn.edu/blurbs/linmultialg/tensorprod.pdf): balancing/universal-property background. The finite-dimensional dual/Hom identification is restricted to its valid finite-dimensional setting; a tensor over a noncommutative ring starts with right/left modules and yields an abelian group unless further scalar structure is supplied.
- [J. S. Milne, Group Theory](https://www.jmilne.org/math/CourseNotes/GT.pdf), Chapter 7: representations, group algebras, semisimplicity and opposite-ring conventions. The group basis remains formal coefficient data; a representation need not embed the algebra. Matrix-block dimension and simple-module dimension remain distinct. Milne's notes presume undergraduate abstract algebra, so they are a correctness supplement, not the introductory teaching sequence.
- [Stacks, Localization](https://stacks.math.columbia.edu/tag/00CM): the equivalence relation allows a denominator-set annihilator. A selected zero divisor can erase nonzero elements. Worked cases distinguish Z[1/3], Z₍₃₎ and Q.
- [Stacks, Nakayama](https://stacks.math.columbia.edu/tag/00DV): finite generation is an essential premise for the taught version. Q=3Q over Z₍₃₎ is the retained counterexample to dropping it.
- [Stacks, Artinian Rings](https://stacks.math.columbia.edu/tag/00J4), especially Lemmas 10.53.3–6: finite maximal-ideal set, radical nilpotence, local decomposition and finite length. These justify the dependency order. A finite chain display alone is not a proof of the general structure theorem.

Public source access above was successful for the cited documents/sections. A later retry of two large Conrad PDFs timed out; their earlier successful reads remain evidence of access, not evidence that every page was reread. Judson's author-hosted HTML returned a gateway error and was not used as a verified-content source. No private PDFs are redistributed.

## Pedagogy: evidence versus design hypotheses

[Freeman et al., 2014](https://doi.org/10.1073/pnas.1319030111) reports a meta-analysis of undergraduate STEM active learning. Its abstract and publication metadata were inspected; this is evidence for active participation generally, not a causal estimate for this application. [Roediger and Karpicke, 2006](https://doi.org/10.1016/j.jml.2006.09.004) addresses repeated retrieval and retention; the accessible publication abstract was inspected, not the full experiment report. Neither establishes that multiple-choice success certifies proof-writing mastery.

Design hypothesis: prediction → manipulation → formal explanation → counterexample → transfer will make each existing lab useful for learning. It remains unvalidated by student research. Practice must require checking premises and explaining the inference, not merely revealing a number. Worked proof steps and paper practice support undergraduate reasoning; automatically scored checks assess the displayed questions only.

Design hypothesis: complementary views of an existing object reduce mistaken identifications. Cube motions therefore connect spatial matrices, permutations on different object sets, orbit/stabilizer counts and characters. Ring quotients connect representative arithmetic, ideal inclusion and field/zero-divisor behavior. The scope of a finite model is stated so its display cannot masquerade as a general proof.

A correct rendered formula, passing schema check or computed example is necessary but insufficient. Independent semantic review, every-lesson browser inspection, negative/boundary calculations and production journey checks remain separate release gates.
