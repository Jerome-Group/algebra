# Teach existing concepts with preserved evidence

The atlas exposed 150 concepts but only 79 guided contracts. Its visual controls and source links were substantially richer than the learning paths made apparent. Completing an assessment could also replace earlier evidence after a question revision, and loading every laboratory inflated the initial JavaScript.

Keep the existing catalogue, routes, mathematical engines, citations and Sites identity. Complete the remaining teaching contracts rather than expand the syllabus. Connect examples, failed hypotheses, justified proof steps and practice; imported proof dependencies remain explicit. Preserve the original 79 assessment contracts so demonstrated competencies retain their meaning.

Use an immediate square-composition activity, reading-stage navigation and optional proof reconstruction. Preserve full reading and reference access. Retain complementary exact views and finite-model limits. No decorative animation or external AI service is required.

Retain device storage keys. Archive superseded valid attempts; protect malformed/future records from automatic overwrite. Back up before changing a record, allow export and reversible reset/restoration, and read current storage before a submission to avoid losing another tab's answer. Storage failures leave explicit session-only feedback.

Load laboratories individually with loading and recovery states. Keep a generated feature/lesson map with source hashes, routes, controls, model dispatch, dependencies and evidence requirements. One structured CLI runs the same engineering, mathematical, rendered and browser checks used by CI. Inventory, passing checks, semantic review and observed browser behavior are separate claims.

Deploy only reviewed source to the original Sites repository, recording the GitHub-to-Sites commit mapping. Preserve the domain and public access setting. Keep an archive-backed previous release and test recovery before accepting production.

## Consequences

- Recognition checkpoints measure their displayed reasoning questions, not independent proof-writing ability.
- Pedagogical effectiveness remains an untested hypothesis until a student study.
- Advanced results may import explicitly named prerequisites; scaffolding does not turn a roadmap into a full proof.
- Browser evidence is tied to the inspected artifact. Source edits invalidate coverage evidence until checks/inspection repeat.
- The initial lesson corpus still contributes substantial JavaScript; deferred labs improve delivery but do not establish a field-performance score.
